DeepSeek Harness 插件 · 开源 MIT · 本机运行

🥬 韭菜盒子 LeekBox

A 股看盘助手，装进 DeepSeek Harness（DSH）的 Web 面板里： 实时行情与大盘指数、分时与前复权 K 线、自选股持仓盈亏与价格预警、 13 项技术信号选股、涨停情绪温度计与龙虎榜、7×24 三源聚合快讯、AI 个股分析。

GitHub 仓库 ★ npm 安装 更新日志

公开免费数据源，无需 API key · 只监听 127.0.0.1 · 数据仅供研究，不构成投资建议

为什么是插件，而不是又一个看盘 App

行情软件不缺，缺的是"待在你自己工作台里的那一个"。LeekBox 把看盘、选股、快讯和 AI 分析塞进 DSH 的同一个面板， 代码全开源、数据链路可审计（每个上游适配器都在 lib/ 里可查），信号与权重写在 lib/signals.js，想改就改。

📈

实时行情与大盘指数

上证 / 深成 / 创业板 / 科创50，15 项实时指标；个股详情弹窗带分时图、日周月与 5/30 分钟前复权 K 线（MA5/10/20 + 成交量 + 十字光标）、主力资金流向、F10 财务摘要。

自选股 · 持仓盈亏 · 价格预警

分组管理，内联编辑持仓成本，按现价实时算浮动盈亏与收益率；行内设「涨到 / 跌破 / 涨跌幅达到」，交易时段自动盯盘，触发 toast + 桌面通知 + 蜂鸣。

🔍

选股器：13 信号 + 7 策略交叉

13 项技术信号（均线、MACD、RSI、KDJ、BOLL、放量、上穿…）加权评分排序；多策略模式取 7 个预设策略的并行交集，按命中数排序。信号定义集中在服务端，界面自动跟随。

🌡️

涨停情绪温度计

市场宽度 40% + 涨停强度 25% + 封板率 20% + 连板高度 15% 加权成 0~100 分，配连板梯队、炸板率、涨跌家数、可展开的涨停池明细。

🐉

龙虎榜与 7×24 快讯

龙虎榜按日期回溯到最近一个已发布的交易日，不把"还没发布"伪装成"没有数据"；新浪 / 东财 / 金十三源快讯跨源去重，重要资讯高亮，可点相关股票。

AI 个股分析

服务端汇总实时行情 + 近 60 日 K 线 + F10 财务后送模型，输出结构化中文分析（含风险提示）；支持 DeepSeek / OpenAI / Anthropic Claude / Kimi / 智谱 / 通义 等，密钥只在服务端。

安装（约 1 分钟）

要求 DeepSeek Harness ≥ 0.1.1-rc.1，且使用 web profile。

# 1) 拿代码
git clone https://github.com/SuCriss/dsh-leekbox.git

# 2) 链接进 web profile 的 node_modules
#    Windows
mklink /J "%DSH_HOME%\profiles\web\node_modules\dsh-leekbox" "<仓库路径>"
#    macOS / Linux
ln -s "<仓库路径>" "$DSH_HOME/profiles/web/node_modules/dsh-leekbox"

# 3) 在 $DSH_HOME/profiles/web/cordis.patch.yml 追加：
#    - insert:
#        - id: leekbox
#          name: 'dsh-leekbox'

# 4) profile watcher 约 1 秒内热重组合；刷新浏览器，侧边栏出现 🥬

完整说明、数据源清单与工程细节见 README。

常见问题

这是网页版还是客户端？要单独装软件吗？
都不是——它是 DSH 的插件，跑在 DSH 的 web profile 里：服务端路由在 DSH 进程内，界面是浏览器里的一个面板。
需要付费行情 API 或注册账号吗？
不需要。行情、指数、K 线、榜单、龙虎榜、快讯都来自公开免费接口（腾讯财经 / 东方财富 / 新浪财经 / 金十数据）。只有 AI 分析需要你自己填模型密钥。
行情有多实时？
交易时段内 30~60 秒轮询，盘中打开的详情窗口跟着刷新；非交易时段与页面在后台时不发请求，回到前台立刻补一次。
支持港股、美股、期货吗？
不支持，只做 A 股：沪深京股票、ETF / 场内基金、可转债、LOF。
自选股和模型密钥会上传到服务器吗？
不会。路由只监听 127.0.0.1，数据落盘在 $DSH_HOME/.leekbox-*.json，密钥只存在服务端、界面只显示脱敏值。
为什么有时右上角显示「休市」？
那是交易日历在说"今天不开市"。日历用指数日 K 反推交易日，并用分时探测区分"今天休市"与"今天的日线还没出"，不会把工作日误报成休市。
